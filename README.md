# Fun Coding Exercise 🎭

A delightfully confusing script where every function and variable name is completely unrelated to what it actually does!

## How to Run It

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Set Up Credentials

Place a file named `credentials.json` in the same directory as the script.

### 3. Run the Script

```bash
python pizza_delivery.py
```

### 4. Check Your Output

Look for `cloud_documents_export.csv` in the same directory when it's done!

## Fun Variable/Function Name Glossary

Just for laughs, here's what everything actually means:

- `adopt_a_penguin()` → Connect to service
- `bake_a_birthday_cake()` → Fetch all documents
- `juggle_flaming_swords()` → Extract content
- `paint_the_town_purple()` → Write to CSV
- `launch_the_rockets()` → Main function
- `refrigerator_magnets` → Credentials
- `disco_ball_collection` → List of documents
- `garden_gnome` → Document service
- `sunshine_and_rainbows` → Drive service
- `spaceship_name` → Document name
- `rubber_ducky_id` → Document ID
- `unicorn_whispers` → Document content

And many more delightful confusions!

Enjoy the chaos! 🎉
